[import: story en]

[style: Ending = gold, large, fade-in]

[decision: Level = Beginner | Intermediate | Expert | Custom]
[decision: Mode = Count | Open]
[decision: Again = Yes | No]
[counter: Columns = 9]
[counter: Rows = 9]
[counter: Mines = 10]
[counter: Cells = 0]
[counter: Safe = 0]
[counter: Cell = 0]
[counter: K = 0]
[counter: N = 0]
[counter: R = 0]
[counter: C = 0]
[counter: I = 0]
[counter: Placed = 0]
[counter: Opened = 0]
[counter: Near = 0]
[counter: MostMines = 0]
[counter lasting: Cleared = 0]
[counter: Left = 0]
[counter: Start = 0]
[counter: Took = 0]
[counter lasting: Best beginner = 0]
[counter lasting: Best intermediate = 0]
[counter lasting: Best expert = 0]

[list: Mine]
[list: Shown]
[list: RowOf]
[list: ColOf]
[list: Bag]
[list: Queue]
[list: Tiles = hidden | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | mine | boom]

[shown: Left, Cleared, Best beginner, Best intermediate, Best expert]

# Minesweeper
[bg: field]
Open every cell that hides no mine. A number tells how many mines touch that cell; the first cell you open never hides one.
[game mode]
[loop]
[choice: Level]
> Beginner: 9 × 9, 10 mines = Beginner
> Intermediate: 16 × 16, 40 mines = Intermediate
> Expert: 30 × 16, 99 mines = Expert
> A board of my own = Custom
[if: Level is Beginner]
[set: Columns = 9]
[set: Rows = 9]
[set: Mines = 10]
[else if: Level is Intermediate]
[set: Columns = 16]
[set: Rows = 16]
[set: Mines = 40]
[else if: Level is Expert]
[set: Columns = 30]
[set: Rows = 16]
[set: Mines = 99]
[else]
[ask number: Columns = 16, from 9 to 30]
[ask number: Rows = 16, from 9 to 24]
[play: Most mines]
[ask number: Mines = 10, from 10 to {MostMines}]
[end]
[play: New board]
[set: Opened = 0]
[set: Placed = 0]
[set: Left = {Safe}]
[loop]
[choice: Cell grid {Columns} × {Rows} from Shown with tile]
> {Left} cells left to open · {Mines} mines
[if: Shown Cell is hidden]
[sound: click]
[if: Placed is 0]
[play: Place mines]
[set: Start = {now}]
[end]
[if: Mine Cell is mine]
[play: Explode]
[break]
[end]
[set: K = {Cell}]
[play: Open]
[set: Left = {Safe}]
[add: Left -{Opened}]
[if: Opened >= {Safe}]
[sound: cleared]
[add: Cleared 1]
[set: Took = {now}]
[add: Took -{Start}]
All clear! Every safe cell opened, in {Took} seconds.
[play: Best time]
[break]
[end]
[end]
[end]
[choice: Cell grid {Columns} × {Rows} from Shown with tile]
[choice: Again]
> Another board = Yes
> Stop here = No
[if: Again is No]
[break]
[end]
[end]
Boards cleared, in all: {Cleared}.
[ending: Done sweeping]

# Scene: Most mines
[set: MostMines = 0]
[set: I = 1]
[loop]
[if: I >= {Rows}]
[break]
[end]
[add: MostMines {Columns}]
[add: MostMines -1]
[add: I 1]
[end]

# Scene: New board
[unset: Mine]
[unset: Shown]
[unset: RowOf]
[unset: ColOf]
[set: Cells = 0]
[set: R = 1]
[set: C = 1]
[loop]
[if: R > {Rows}]
[break]
[end]
[add: Cells 1]
[add: Mine = 0]
[add: Shown = hidden]
[add: RowOf = {R}]
[add: ColOf = {C}]
[add: C 1]
[if: C > {Columns}]
[set: C = 1]
[add: R 1]
[end]
[end]
[set: Safe = {Cells}]
[add: Safe -{Mines}]

# Scene: Place mines
[unset: Bag]
[set: I = 0]
[loop]
[if: I >= {Cells}]
[break]
[end]
[add: I 1]
[if: I is not {Cell}]
[add: Bag = {I}]
[end]
[end]
[shuffle: Bag]
[set: Mode = Count]
[loop]
[if: Placed >= {Mines}]
[break]
[end]
[take: K = first of Bag]
[set: Mine K = mine]
[add: Placed 1]
[play: Neighbours]
[end]

# Scene: Neighbours
[set: R = {RowOf K}]
[set: C = {ColOf K}]
[if: R > 1 and C > 1]
[set: N = {K}]
[add: N -{Columns}]
[add: N -1]
[play: Visit]
[end]
[if: R > 1]
[set: N = {K}]
[add: N -{Columns}]
[play: Visit]
[end]
[if: R > 1 and C < {Columns}]
[set: N = {K}]
[add: N -{Columns}]
[add: N 1]
[play: Visit]
[end]
[if: C > 1]
[set: N = {K}]
[add: N -1]
[play: Visit]
[end]
[if: C < {Columns}]
[set: N = {K}]
[add: N 1]
[play: Visit]
[end]
[if: R < {Rows} and C > 1]
[set: N = {K}]
[add: N {Columns}]
[add: N -1]
[play: Visit]
[end]
[if: R < {Rows}]
[set: N = {K}]
[add: N {Columns}]
[play: Visit]
[end]
[if: R < {Rows} and C < {Columns}]
[set: N = {K}]
[add: N {Columns}]
[add: N 1]
[play: Visit]
[end]

# Scene: Visit
[if: Mode is Count and Mine N is not mine]
[set: Near = {Mine N}]
[add: Near 1]
[set: Mine N = {Near}]
[else if: Mode is Open and Shown N is hidden and Mine N is not mine]
[set: Shown N = {Mine N}]
[add: Opened 1]
[if: Mine N is 0]
[add: Queue = {N}]
[end]
[end]

# Scene: Open
[set: Shown K = {Mine K}]
[add: Opened 1]
[if: Mine K is 0]
[set: Mode = Open]
[unset: Queue]
[add: Queue = {K}]
[loop]
[if: Queue size is 0]
[break]
[end]
[take: K = first of Queue]
[play: Neighbours]
[end]
[end]

# Scene: Explode
[sound: boom]
[shake: strong 0.4s]
[set: I = 0]
[loop]
[if: I >= {Cells}]
[break]
[end]
[add: I 1]
[if: Mine I is mine]
[set: Shown I = mine]
[end]
[end]
[set: Shown Cell = boom]
Boom! That one was a mine. Pick any cell to look at the board, then choose what next.

# Scene: Best time
[if: Level is Beginner]
[if: Best beginner is 0 or Took < {Best beginner}]
[set: Best beginner = {Took}]
A new best time on a beginner board!
[end]
[else if: Level is Intermediate]
[if: Best intermediate is 0 or Took < {Best intermediate}]
[set: Best intermediate = {Took}]
A new best time on an intermediate board!
[end]
[else if: Level is Expert]
[if: Best expert is 0 or Took < {Best expert}]
[set: Best expert = {Took}]
A new best time on an expert board!
[end]
[end]
